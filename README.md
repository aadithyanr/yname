# yname

Generate a YC startup name before someone else does.

https://github.com/user-attachments/assets/b884127d-050b-451d-8dd8-2e6c1068a47c

Each name is generated by a tiny character-level neural network trained from
scratch on 6,194 YC company names. The dataset was scraped with
[Context.dev](https://context.dev/).

The model runs locally in your browser. No LLM and no backend.

## Run locally

```bash
cd web
npm install
npm run dev
```

## Train the models

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r model/requirements.txt

python model/train.py \
  --data data/yc_name_training_corpus.csv \
  --output-dir model/artifacts
```

```bash
cd web
npm run export-models
```
